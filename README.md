# UNFAIR ADVENTURE

ブラウザで遊べる、理不尽系2D横スクロールアクションの初期プロトタイプです。

## 起動方法
1. ZIPを展開します。
2. `index.html` をブラウザで開きます。
3. 「冒険を始める」を押します。

GitHub Pagesで公開する場合：
1. GitHubで新しいリポジトリを作成。
2. このフォルダ内のファイルをリポジトリ直下にアップロード。
3. Settings → Pages → Deploy from a branch → `main` / `/ (root)` を選択して保存。

## 操作
- 移動：← → または A / D
- ジャンプ：Space / W / ↑
- タッチ端末：画面下のボタン

## 現在の実装
- 横スクロールの2Dステージ
- ジャンプ、足場、穴、トゲ、コイン、ゴール
- ステージ開始時に4〜6個の隠し即死ルールを抽選
- 隠しルールと独立したランダム即死判定
- Minecraft風の死亡画面（ゲーム画面上に赤色・不透明度80%のレイヤー）
- 同じステージの再挑戦、ホーム画面への帰還
- タッチ操作

## プレイヤーの見た目を変える場所

プレイヤーの見た目は `game.js` の `drawWorld()` 内にある `// プレイヤー` の直後です。
現在は `ctx.fillRect(...)` で四角形を重ねて描いています。

- `player.x`, `player.y` は描画位置
- `player.w`, `player.h` は当たり判定の幅・高さ（見た目だけ変えるなら基本そのまま）
- `ctx.fillStyle` は次に描く色
- `ctx.fillRect(x, y, width, height)` は四角形を描く命令

色を変えるだけなら、`ctx.fillStyle = "#263a48";` などのカラーコードを変更します。
形を変えるなら、プレイヤー描画部分の `fillRect` を追加・変更します。
敵の描画部分や背景・地形の描画部分とは別なので、`// プレイヤー` から `ctx.restore()` の直前までを編集してください。


## Ver.0.4 変更点
- 地面の高さをY=430に変更し、iPadの画面下部にあるタッチ操作ボタンとプレイヤーが重なりにくい配置に変更。
- 各ステージにアイテムボックスを3個追加。下から叩くとコインまたは謎の巨大化アイテムが出現。
- 出現アイテムはゆっくり落下し、地面に着地。
- 巨大化アイテムを取るとプレイヤーの身長と当たり判定が2倍。
- 巨大化中に隠し即死ルール・敵・トゲに触れると通常サイズに戻り、2秒間無敵。
- 独立ランダム即死と奈落死は巨大化・無敵時間でも防げない。
- 巨大化アイテム取得を対象とする新しい隠しルールを追加。
- 死亡画面のログとボタンが小さい画面でも見えるよう、死亡パネルをスクロール可能に調整。


## Ver.0.5 変更点
- 巨大化アイテムの見た目を、アップロードされた背景透過PNGの緑色リーフ画像に変更。
- 画像は `assets/maple_powerup.png` に配置。
- 画像ファイル名を変更する場合は、`game.js` 冒頭の `POWERUP_IMAGE_PATH` を変更する。
- 画像は透過を維持して描画し、ピクセル感を残すため拡大補間を無効化。
