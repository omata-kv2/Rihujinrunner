# UNFAIR ADVENTURE

ブラウザで遊べる、理不尽系2D横スクロールアクションの初期プロトタイプです。

## 起動方法
1. ZIPを展開します。
2. `index.html` をブラウザで開きます。
3. 「冒険を始める」を押します。

GitHub Pagesで公開する場合：
1. GitHubで新しいリポジトリを作成。
2. このフォルダ内のファイルをリポジトリ直下にアップロード。
3. Settings → Pages → Deploy from a branch → `main` / `/ (root)` を選択して保存。

## 操作
- 移動：← → または A / D
- ジャンプ：Space / W / ↑
- タッチ端末：画面下のボタン

## 現在の実装
- 横スクロールの2Dステージ
- ジャンプ、足場、穴、トゲ、コイン、ゴール
- ステージ開始時に4〜6個の隠し即死ルールを抽選
- 隠しルールと独立したランダム即死判定
- Minecraft風の死亡画面（ゲーム画面上に赤色・不透明度80%のレイヤー）
- 同じステージの再挑戦、ホーム画面への帰還
- タッチ操作

## 開発メモ
これは最初の動作確認用プロトタイプです。今後、キャラクター・背景・地形のピクセルアート化、アニメーション、音、ステージ生成、死亡ログの拡充などを行います。
